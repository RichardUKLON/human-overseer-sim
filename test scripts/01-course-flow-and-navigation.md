# 01 — Course flow and navigation

You are testing **The Human Overseer** eLearning course. Test the learner journey without judging whether the course content is correct.

## Goal

Verify that a learner can enter, progress through, leave, resume, replay, and reset the course without dead ends, lost progress, or misleading labels.

## Test procedure

1. Open the course from a fresh browser session.
2. Check the landing page, start screen, scenario map, scenario briefing, review desk, consequence screen, debrief, checkpoint, calibration profile, field guide, and reset control.
3. Complete S01, then one scored scenario. Confirm the map and progress counter update.
4. Leave a scenario before committing, return to the map, then open it again. Record what remains selected and whether that behaviour matches the interface copy.
5. Complete six scenarios and confirm the halfway checkpoint appears once only.
6. Complete all 12 scenarios and confirm the calibration profile appears.
7. Replay a completed scenario. Confirm its replay result does not overwrite the first scored attempt.
8. Use reset. Confirm the confirmation text is accurate and the course returns to a clean state.
9. Use browser back/forward at each screen where practical. Record broken screens, duplicate scoring, lost navigation, or stale content.

## Report format

For each issue provide: step, expected result, actual result, severity (blocker/high/medium/low), screenshot or exact visible text, and a suggested fix. End with a table of all screens reached and screens that could not be reached.
